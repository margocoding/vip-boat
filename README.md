# Vip Boat — новая главная (Next.js, App Router, TypeScript)

Главная страница в композиции nauyachts.com с данными vip-boat.ru: те же категории, лодки, цены, контакты и тексты.

## Запуск

```bash
npm install
node scripts/import-images.mjs "/путь/к/Аренда яхты в СПБ с капитаном, моторная яхта на прокат_files"
npm run dev      # http://localhost:3000
```

Скрипт копирует фото из папки `…_files` (рядом с сохранённой страницей) в `public/vip-images`.
Пока картинок нет, блоки показывают бирюзовый градиент. Фоновые слайды hero грузятся с облака сайта
(`storage.yandexcloud.net/vip-boat-images`), их копировать не нужно.

## Где что менять

- `src/data/site.ts` — контакты, соцсети, реквизиты, меню, 6 категорий (с картинками и счётчиками), тексты блоков, отзывы.
- `src/data/boats.ts` — 9 яхт с главной: название, длина, вместимость, цена и цена без скидки, удобства, фото.
- `src/app/globals.css` — стили; фирменные цвета сайта в `:root` (`--navy: #002839`, `--sand: #07c4cf`).
- `src/app/api/enquire/route.ts` — приём заявок (сейчас пишет в лог). Подключите Telegram/почту/CRM.

## Секции главной

Hero (слайдшоу) → полоса категорий → манифест + цифры (28/28/21) → 4 блока «Почему Vip-Boat» →
«Яхты по размеру» (вкладки по длине) → «Три типа судов» → плитки 6 категорий → каталог яхт →
«Для любого повода» → отзывы → футер с формой, реквизитами ИП. Плавающие кнопки: Позвонить / Max / Telegram.

## Важно

- Внутренние страницы (`/arenda-yachty`, `/arenda-catera`, `/arenda-teplohoda`, `/arenda-heli`, `/routes`,
  `/events`, `/cruises`, `/catering`, `/news`, `/contacts`, `/arenda-yachty/<slug>` и др.) в проекте ещё не созданы:
  ссылки сохранили адреса старого сайта.
- В `src/data/boats.ts` по каждой яхте указаны первые 5 фото; на сайте их больше.
- E-mail и адрес на главной старого сайта не указаны, поэтому не выводятся.
- Логотип в шапке — текстовый «VIP BOAT». Файл `logo.png` есть в папке `_files`, при желании подставьте его в `Header.tsx`.
- Внизу старого сайта есть пометка о контенте, сгенерированном ИИ, — она перенесена в футер.
