# Vip Boat

Прототип аренды яхт, катеров и теплоходов в Санкт-Петербурге на базе готового лендинга. Главная, каталоги и карточки используют исходные шрифты, фотографии и палитру.

## Запуск

```sh
npm ci
npm run dev
npm run build
npm start
```

Адрес по умолчанию — http://localhost:3000. Для оценки скорости используйте production-сборку. Фото в WebP входят в репозиторий, отдельная загрузка при старте не требуется.

## Что можно проверить

- Выбрать тип судна, отфильтровать теплоходы по вместимости и палубам и отсортировать по цене. Фильтры отправляются методом GET, результаты отрисовываются на сервере.
- Навести курсор на карточку, чтобы увидеть второе фото. На телефоне оба фото доступны переключателем в карточке.
- В карточке изменить дату, время, длительность, число гостей, кейтеринг и услуги. По часам учитываются демонстрационные коэффициенты сезона, выходных и вечернего времени. В форму передаётся состав расчёта.
- На [AZIMUT 62](/arenda-yachty/azimut-62) открыть 3D-тур, который загружается по кнопке. Посмотреть маршруты и примеры меню в разделе кейтеринга.
- Переключить язык на английский или китайский. Для них есть сокращённая главная, навигация, каталог, карточка, калькулятор и страницы услуг. Названия судов сохранены.

Заявка проходит демонстрацию в браузере. Интеграции, бронирование, админка и согласованные юридические тексты относятся к следующему этапу. Флот представлен выборкой, карточки и тарифный пример не подтверждают доступность судна или итоговую цену.

## Где править после согласования

- `src/data/site.ts` и `src/data/boats.ts` — данные лендинга и яхт.
- `src/data/rental.ts` — демонстрационный флот, характеристики и опциональный адрес 3D-тура. В `seo` можно задать title и description для карточки.
- `src/lib/estimate.ts` — коэффициенты, кейтеринг и услуги.
- `src/data/editorial.ts` — маршруты, кейтеринг, мероприятия и круизы.
- `src/data/media.json` и `public/media` — фото, размеры вариантов и ссылки на оригиналы.
- `src/lib/metadata.ts`, `src/app/robots.ts`, `src/app/sitemap.ts` — SEO. Для другого канонического домена задайте `VIP_BOAT_SITE_URL`.

Главная и карточки предрендерятся в HTML при сборке. Разделы с фильтрами рендерятся на запросе. Для быстрой загрузки первое фото имеет высокий приоритет, остальные используют локальные размеры WebP и отложенную загрузку. У прототипа нет стартовых запросов к аналитике или 3D-турам.
